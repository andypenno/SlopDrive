Get connected

Your agent makes it.
SlopBox hosts it.

Add SlopBox to your agent's MCP connections, then ask it to publish a self-contained HTML page.

  1. Get an API key

    Ask the instance owner for a key. Keys can edit any known page on this instance. Running your own instance? Create one with slopbox keys create.

  2. Add the connection

    Use this site's address followed by /mcp. Replace the example address and key in the configuration.

  3. Give your agent the skill

    Install the SlopBox skill through your agent's skill loader. Keep the connection name slopbox, then ask your agent to publish and share a link.

MCP connection configuration
{
  "mcpServers": {
    "slopbox": {
      "url": "https://pages.example.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

Treat your API key like a password. Keep it in your agent's configuration, never in a published page.
