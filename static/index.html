SlopBox

A host for single-file HTML pages. Each upload gets a random ID. The URL /<upload-id> shows the latest version. Add ?q=<sha256-hash> to view one version. There is no directory of pages.

Connect an MCP client

Configure a streamable HTTP MCP server at this site's /mcp endpoint. Send Authorization: Bearer <API_KEY> on every request. The tools are upload_html, update_html, list_versions, and get_html_url.

{
  "mcpServers": {
    "html_host": {
      "url": "https://your-host.example/mcp",
      "headers": { "Authorization": "Bearer YOUR_API_KEY" }
    }
  }
}

Install the agent skill

The skills/slopbox directory in the private SlopBox repository contains a skill to advise your agent. Install it using your agent's skill loader, then configure the MCP connection above.

API keys are created locally with slopbox keys create. The HTTP upload API accepts POST /upload and POST /upload/<upload-id> with a file multipart field. Version lists require GET /upload/<upload-id>/versions and the same bearer key.
